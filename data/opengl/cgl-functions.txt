# The functions of the CGL headers (OpenGL.h, CGLCurrent.h, CGLDevice.h, CGLIOSurface.h):
# helpers/write_opengl_headers.py declares them in OpenGL.framework/Headers, and they are exports of
# OpenGL.tbd.  Apple's headers are not a source.  A function is listed when at least two open
# source projects name it, and the header comes from the comments of the sources that name the
# header (apitrace specs/cglapi.py: "CGLCurrent.h", "OpenGL.h", "CGLIOSurface.h", "CGLDevice.h").
# The types of the parameters follow the C declarations of mesa src/glx/apple/apple_cgl.h and
# apitrace specs/cglapi.py (also vogl glspec/cgl.spec, servo/cgl-rs src/cgl.rs).
# Columns, separated by "|": header | return type | name | parameters | sources, where the sources
# are the names of the projects that use the function (the keys of cgl-enums.txt, plus cgl-rs,
# vogl, mesa, glutin: servo/cgl-rs, ValveSoftware/vogl glspec/cgl.spec, mesa apple_cgl.c).
