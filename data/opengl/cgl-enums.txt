# The constants of the CGL headers (CGLTypes.h, CGLRenderers.h): helpers/write_opengl_headers.py
# writes them into OpenGL.framework/Headers.  Apple's headers are not a source: every value is
# declared by an open source project that wrote it down, and every name is used or listed by
# open source (docs/SOURCES.md, "OpenGL.framework").
# Columns:
#   group   the type that the constant belongs to: error CGLError, pfa CGLPixelFormatAttribute,
#           rp CGLRendererProperty, ce CGLContextEnable, cp CGLContextParameter,
#           go CGLGlobalOption, oglp CGLOpenGLProfile, renderer (a renderer ID, an int)
#   name    the constant
#   value   its value
#   values  the projects whose source declares this value (all that do agree):
#             cgl-rs   servo/cgl-rs d97cc08, src/cgl.rs (MIT or Apache-2.0)
#             vogl     ValveSoftware/vogl 434dcc5, glspec/cglenum.spec (MIT)
#             apitrace apitrace/apitrace 28bb3ab, dispatch/glimports.hpp (MIT)
#             factor   factor/factor f05a4e9, basis/core-graphics/core-graphics.factor (BSD-2-Clause)
#   named   the other sources that use or list the name (no value):
#             apitrace-spec  apitrace/apitrace 28bb3ab, specs/cglapi.py (MIT)
#             wine           wine-mirror/wine ecca8e7, dlls/winemac.drv/opengl.c (LGPL-2.1)
#             xquartz        XQuartz/xorg-server 0ea9b59, hw/xquartz/GL/indirect.c (MIT)
#             mesa           mesa 7564f95, src/glx/apple/apple_visual.c, apple_glx_context.c (MIT)
#             renderdoc      baldurk/renderdoc, renderdoc/driver/gl/cgl_platform.cpp (MIT)
#             guide          Apple's archived "OpenGL Programming Guide for Mac" (pages of
#                            developer.apple.com/library/archive/documentation/GraphicsImaging/Conceptual/OpenGL-MacProgGuide)
# group  name  value  values  named
