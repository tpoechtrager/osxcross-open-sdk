#            install_own_files);
#            fallback: copied from data/headers/<path> only for a release
#            whose project does not have the file (lib/frameworks.sh)
#   note     the rest of the line, optional: it follows the file in the
#            list of LICENSES.md of the SDK (write_licenses.py)
